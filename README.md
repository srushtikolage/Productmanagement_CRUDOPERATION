🛍️ Product Management System

A simple and clean Product Management System built for learning and practice purposes. This project demonstrates basic CRUD operations using ASP.NET MVC.

🚀 Features

✨ Add new products
📋 View product list
✏️ Edit existing products
❌ Delete product

🛠️ Tech Stack
💻 Backend: ASP.NET MVC
🔗 ORM: Entity Framework (Code First Approach)
🎨 Frontend: HTML, CSS, Bootstrap
🗄️ Database: SQL Server

📚 Purpose

This project is created for learning and practice to understand:

CRUD operations in real applications
MVC architecture
Entity Framework with Code First approach
Database connectivity

📸 UI Overview

Simple and responsive UI built using Bootstrap for better user experience.

⚙️ How to Run
Clone the repository
Open in Visual Studio
Restore NuGet packages
Update database using migrations
Run the project

🙌 Conclusion

This mini project helped me strengthen my understanding of full-stack development basics using ASP.NET MVC.
